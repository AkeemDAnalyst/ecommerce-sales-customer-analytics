# E-commerce Sales and Customer Analytics

## Description
This project is focused on analyzing e-commerce sales and customer data using SQL. It includes SQL queries for analyzing trends, customer behaviors, and sales performance.

## Files
- `queries.sql`: Contains SQL queries for data analysis.
- `schema.sql`: Includes the schema design for the database.

## Highlights
- Key metrics derived from the data.
- Technologies used: MySQL, PostgreSQL.
- Challenges and solutions during the analysis.

## How to Use
1. Clone the repository: `git clone https://github.com/AkeemDAnalyst/ecommerce-sales-customer-analytics.git`
2. Navigate to the SQL project folder: `cd path-to-sql-folder`
3. Run the SQL queries using your preferred database tool.
